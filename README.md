# 📖 Overview
The **Bookstore App** is a full-stack web application built using the **MERN (MongoDB, Express, React, Node.js)** stack. Users can add, delete, modify book details. Each book entry displays essential information, including the book name, author name, and
date of publication.

# 🚀 Features
- Browse books details
- Edit and delete book
- Responsive design

# 🛠️ Tech Stack
- **Frontend:** React, Redux, Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
